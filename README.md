# 🚀 Космическая открытка на GitHub Pages

Простая открытка-поздравление: открываешь ссылку — видишь конверт «письмо из космоса»,
нажимаешь — печать слетает, конверт открывается, и появляется открытка среди звёзд, планет и комет.

## Как поменять открытку в коде

Открой `config.js` и поменяй значения:

```js
const CARD = {
  title: "С Днём Рождения!",   // заголовок
  to: "Дорогой друг",          // кому
  message: "Текст поздравления", // \n — перенос строки
  from: "Твой друг",           // от кого
  color: "#a78bfa",            // цвет свечения и планеты
  emoji: "🚀",                  // эмодзи
};
```

Закоммить и запушь — через минуту открытка на сайте обновится.

## Как включить GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source:** `Deploy from a branch`, ветка `main` (или эта ветка), папка `/ (root)` → **Save**.
3. Через 1–2 минуты появится ссылка вида
   `https://<твой-ник>.github.io/automatic-fishstick/` — её и кидай.

## Своя открытка без правки кода

На открытке нажми **«✏️ Сделать свою»**, впиши текст, выбери цвет и нажми
**«Скопировать ссылку»**. Все данные сохраняются прямо в ссылке, например:

```
https://<ник>.github.io/automatic-fishstick/?to=Маша&title=С%20Новым%20годом!&color=%2300a86b&emoji=🎄
```

Параметры ссылки: `title`, `to`, `message` (или `text`), `from`, `color`, `emoji`.
Если параметра нет в ссылке — берётся значение из `config.js`.
